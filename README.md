# Простой пример с Docker

Этот проект демонстрирует простой пример использования Docker и Docker Compose для запуска многосервисного приложения с бэкендом и фронтендом.

## Структура проекта

- `backend/` - сервис бэкенда на Node.js
- `frontend/` - фронтенд, обслуживаемый через Nginx
- `docker-compose.yml` - конфигурация Docker Compose для сборки и запуска обоих сервисов

## Требования

- Docker
- Docker Compose

## Как запустить

Для сборки и запуска сервисов выполните команду в корне проекта:

```bash
docker-compose up --build
```

Эта команда соберет Docker-образы для бэкенда и фронтенда и запустит контейнеры.

## Бэкенд

Бэкенд — это приложение на Node.js, работающее на порту 5000 внутри контейнера. Собирается с помощью `backend/Dockerfile`.

## Фронтенд

Фронтенд — это статический сайт, обслуживаемый Nginx, собираемый с помощью `frontend/Dockerfile`.

## Остановка сервисов

Для остановки контейнеров нажмите `Ctrl+C` в терминале с запущенным docker-compose или выполните:

```bash
docker-compose down
```

## Примечания

- Файл `docker-compose.yml` определяет сервисы и их контексты сборки.
- Убедитесь, что Docker запущен на вашем компьютере перед выполнением команд.
